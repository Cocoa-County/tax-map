New to project creation?

Start with Build with an AI agent. Install and sign into one CLI, then paste the short setup request. The agent follows SETUP.md to install requirements and activate one skills/MCP plugin. Once live readiness is verified, say “Build a taxmap app for Martinez, CA.” using your city/state. There is no blanket restart requirement; current Codex requires a new session after installation. The agent derives routine settings and continues through research, one exact content review and a checked local preview. Matching projects resume; ambiguous or conflicting folders require a decision. Nothing is published automatically.

Prefer a walkthrough? Say “Create a new taxmap project. Walk me through the setup.” Individual skills and the manual CLI workflow remain available, with the same evidence and privacy requirements. You can enable, disable, or remove the tools without deleting your projects.

AI agents can read the plain-text playbook and documentation index.
