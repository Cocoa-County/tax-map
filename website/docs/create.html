New to project creation?

Start with Build with an AI agent. Install and sign into one CLI, then paste the short setup request. The agent downloads taxmap and follows SETUP.md to install requirements and one skills/MCP plugin. Restart, then ask the agent to create a project; it asks for settings and creates your chosen folder. No manual directory-creation command or direct installer is required. Nothing is published automatically. You can enable, disable, or remove the tools without deleting your projects.

AI agents can read the plain-text playbook and documentation index.
